# Travel-Booking-Website


A simple travel booking demo built with HTML, CSS, and JavaScript.

## Features
- Destination listings with name, country, price, and image
- Search filter by destination or country
- Booking form with name, email, departure, and return dates
- Confirmation alert on booking
